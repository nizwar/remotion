# openWanim()<AvailableFrom v="4.0.542" />

Decrypts the manifest of a `.wanim` file in Node.js and Bun. Throws if the file was modified, or if a custom key is missing or wrong.

```ts twoslash title="open.ts"
import {readFileSync} from 'node:fs';
import {openWanim} from '@remotion/wanim';

const {manifest, readAtlas} = openWanim({
  file: new Uint8Array(readFileSync('out/my-comp.wanim')),
  key: null,
});

console.log(manifest.frameCount);
const png = readAtlas(0);
```

## Arguments

An object with the following properties:

### `file`

The file as a `Uint8Array`.

### `key`

The custom key of the file, or `null` if it uses the official key.

## Return value

An object with the following properties:

### `manifest`

The size, frame rate, atlases, sprites and frames of the animation.

### `readAtlas()`

Takes the index of an atlas and returns its PNG file as a `Uint8Array`, or its WebP file if `manifest.atlases[index].format` is `webp`.

### `readTimeline()`

For a file of version 2: Returns the draws of each frame, each with a `sprite`, a `matrix` and an `alpha`. Throws for other versions.

### `readScene()`

For a file of version 3: Returns `draws`, every different draw once, `lists`, every different frame once as indices into `draws`, and `frames`, which holds for each animation key an index into `lists` per frame. Throws for other versions.

```ts twoslash title="frames-of-an-animation.ts"
import {readFileSync} from 'node:fs';
import {openWanim} from '@remotion/wanim';

const {readScene} = openWanim({
  file: new Uint8Array(readFileSync('out/my-comp.wanim')),
  key: null,
});
const scene = readScene();
const idle = (scene.frames.idle ?? []).map((list) =>
  (scene.lists[list] ?? []).map((draw) => scene.draws[draw]),
);
```
