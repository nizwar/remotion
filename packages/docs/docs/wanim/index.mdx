# @remotion/wanim<AvailableFrom v="4.0.542" />

Exports a composition as a `.wanim` file: A single encrypted binary with texture atlases and the coordinates of each frame, which native apps can play on the GPU.

Frames are trimmed to their visible pixels, and repeated or moved pictures are stored once.

<Installation pkg="@remotion/wanim" />

## Creating a file

Render with [`npx remotion wanim`](/docs/cli/wanim):

```bash
npx remotion wanim render src/index.ts my-comp out/my-comp.wanim
```

Or use [the Studio](/docs/studio): Click Render and choose the Wanim tab.

Render a composition without a background to keep it transparent.

## Formats

- Frames, the default: One picture per frame. Opens in every `.wanim` player.
- Layers, with `--layers`: A `.wanim` file of version 2. The page is split into parts, and a part that only moves, turns, scales or fades is stored once. Needs a player with version 2 support.
- SVGA, with an output name ending in `.svga`: The same layers in the open [SVGA](https://github.com/svga/SVGA-Format) format, without encryption.

Parts with effects that cannot be split, like a filter over a group, are stored as pictures, so every composition can be exported.

## Frame rate and image rate

`--frame-rate` lowers the number of frames without changing the duration. `--image-rate` lets parts that change their look get a new picture less often, while moves stay smooth. Both are also in the Picture section of the Studio.

## Playing a file

`.wanim` is encrypted with an official key that is built into `@remotion/wanim` and the official players, so those open every file without any setup. Other tools cannot read it.

`packages/wanim` contains the format specification in `SPEC.md` and sample files to test against in `fixtures/`. The Kotlin, Swift and Flutter players live in the `WBlue-Indonesia/WAnim` repository.

## Custom keys

A file can use a key of its own instead, which only apps that have this key can open. Create one with `npx remotion wanim keygen` and set it as `WANIM_KEY` when rendering.

## Limitations

Keep animations small. Atlases are decoded to textures, so memory depends on the number of unique pixels and not on the file size. Fullscreen animations should use a video instead.

`.wanim` files have no audio.
