# generateWanimKey()<AvailableFrom v="4.0.542" />

Returns a random custom key for `.wanim` files as 64 hexadecimal characters. Files use the official key unless you pass a custom key.

```ts twoslash title="key.ts"
import {generateWanimKey} from '@remotion/wanim';

const key = generateWanimKey();
```
